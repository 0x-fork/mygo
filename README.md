# MyGo

MyGo is a desktop framework based on System Webview (by default), or bundled CEF, written in Golang.

## Plan

- v0.1: System Webview support
- v0.2: Bundled CEF option

## Project

- Focused on ultra-low memory usage, high performance, low CPU usage
- Ergonomic API, great DX

## Getting started

```sh
bunx mygo-cli init my-app
cd my-app
bun run dev
```

Read the [documentation](docs/README.md).
